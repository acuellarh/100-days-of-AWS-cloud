# ☁️ KodeKloud AWS Challenges

Este repositorio reúne los retos de AWS que voy completando en [KodeKloud](https://kodekloud.com) como parte de mi aprendizaje en la nube.

## 🎯 Objetivo

Documentar cada reto con su contexto, la solución aplicada y los conceptos aprendidos, para afianzar el conocimiento práctico en servicios de AWS como EC2, S3, IAM y VPC, y tener una referencia a la que volver en el futuro.

## 📖 Contexto

Los retos simulan escenarios reales del equipo **Nautilus DevOps**, que migra parte de su infraestructura a AWS de forma incremental: en lugar de una sola migración masiva, el trabajo se divide en tareas pequeñas y manejables. Cada reto representa uno de esos pasos.
